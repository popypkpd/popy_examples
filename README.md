# PoPy for PK/PD Examples Repository

This is a repository of model+data examples using PoPy for PK/PD (product.popypkpd.com).

Examples using the tutorial ("tut" or "mtut") structure generate their own data and therefore do not require a data file to be provided.

Examples using the fit ("fit" or "mfit") structure require a separate data file.

Data files are given in a format readable by both PoPy and, where appropriate, Nonmem or other NLME packages.
